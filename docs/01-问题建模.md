# 问题建模：停车场电动汽车有序充电调度

## 1. 问题的现实来源

一个停车场里有 $N$ 个交流充电桩，它们共享一台容量有限的变压器；停车场屋顶装有光伏。

车主把车停进来、插上枪，几小时后回来取车。**车主只关心离开时电量够不够，并不关心这几小时里具体是哪几分钟在充电。**

这个信息差就是全部机会所在：

- 如果每辆车一插上就满功率充电（现实中最常见的情况），充电负荷会在到达高峰处叠加成一个尖峰，顶到甚至越过变压器容量，而且恰好在电价最贵、碳强度最高的时段买电；
- 而如果把充电时刻当作可自由安排的资源，就可以把这部分负荷平移到光伏出力最高、碳强度最低的时段——用自己屋顶发的电，既不计电费也不计碳排放。

这是一个典型的**用电时间可平移**的调度问题。

## 2. 符号定义

| 符号 | 含义 | 单位 |
|---|---|---|
| $V=\{1,\dots,M\}$ | 当日需要充电的车辆集合 | — |
| $T=\{0,\dots,95\}$ | 时段集合，一天离散为 96 段 | — |
| $\Delta t$ | 单个时段长度，取 0.25 | h |
| $a_i,\ d_i$ | 车辆 $i$ 的到达时段、离开时段 | — |
| $E_i$ | 车辆 $i$ 需要充入的电量 | kWh |
| $P_r$ | 单桩额定功率 | kW |
| $N$ | 充电桩数量 | 个 |
| $P_{\max}$ | 变压器容量上限 | kW |
| $PV_t$ | 时段 $t$ 的光伏出力 | kW |
| $c_t$ | 时段 $t$ 的分时电价 | 元/kWh |
| $e_t$ | 时段 $t$ 的电网碳排放强度 | kgCO₂/kWh |

## 3. 决策变量

$$x_{i,t}\in[0,\ P_r]\qquad y_{i,t}\in\{0,1\}$$

- $x_{i,t}$：车辆 $i$ 在时段 $t$ 的充电功率（连续变量，可取 0 到额定功率之间的任意值）
- $y_{i,t}$：车辆 $i$ 在时段 $t$ 是否占用充电桩（0-1 变量）

由此得到两个派生量：

$$L_t=\sum_{i\in V}x_{i,t}\qquad G_t=\max\!\big(0,\ L_t-PV_t\big)$$

$L_t$ 是充电总负荷，$G_t$ 是**需要从电网购买**的功率。注意天然气、风电、光伏自发自用的部分不计入 $G_t$，这一点是后面"绿电直供同时省钱和减碳"的关键。

## 4. 目标函数

$$\min\ Z=\alpha\underbrace{\sum_{t\in T}c_tG_t\Delta t}_{\text{电费}}+\beta\underbrace{\sum_{t\in T}e_tG_t\Delta t}_{\text{碳排放}}+\gamma\underbrace{\max_{t\in T}L_t}_{\text{峰值负荷}}$$

三个权重 $(\alpha,\beta,\gamma)$ 对应三种决策偏好：

| 偏好 | $(\alpha,\beta,\gamma)$ | 含义 |
|---|---|---|
| 经济优先 | $(1,\ 0,\ 0)$ | 只关心电费 |
| 绿色优先 | $(0,\ 1,\ 0)$ | 只关心碳排放 |
| 平衡 | $(w_1,\ w_2,\ w_3)$ | 按比例加权 |

## 5. 约束条件

**C1 需求满足**：每辆车在其停留区间内累计充入的电量不少于需求

$$\sum_{t=a_i}^{d_i-1}x_{i,t}\Delta t\ \ge\ E_i\qquad\forall i\in V$$

**C2 时间窗口**：不在场时不能充电

$$x_{i,t}=0\qquad\forall t\notin[a_i,\ d_i)$$

**C3 功率上限与桩占用**：单桩功率不超过额定值，且只有占用充电桩才能充电

$$x_{i,t}\le P_r\,y_{i,t}$$

**C4 桩数量**：同一时段同时充电的车辆数不超过充电桩数

$$\sum_{i\in V}y_{i,t}\ \le\ N\qquad\forall t\in T$$

**C5 变压器容量**：充电负荷不超过变压器上限

$$L_t\le P_{\max}\qquad\forall t\in T$$

## 6. 问题性质

把每辆车的充电过程看作一个**可在时间上中断、但必须在其截止时间前完成规定工作量**的任务，则本问题等价于带释放时间与截止时间的并行机调度问题，属于 NP-hard。

规模上：$M$ 辆车 × 96 个时段，$x$ 有 $96M$ 个连续变量、$y$ 有 $96M$ 个 0-1 变量。当 $M=40$ 时是 3840 个连续变量加 3840 个 0-1 变量，属于中小规模 MILP，用分支定界在离线环境可以求解到最优。

**但我们选择启发式而不是精确求解**，原因有三：

1. **赛制要求**：正式比赛是 21 小时现场开发 + 在线评测，评测平台通常对单次求解有时间限制；启发式求解时间为毫秒级，可以反复调参、快速迭代。
2. **数据不确定性**：赛题的约束可能比上述模型更多（三相不平衡、V2G、储能等），模型改动的成本远高于启发式。
3. **可解释性**：路演需要把决策逻辑讲清楚。启发式的每一步都能对应一句人话，评委容易接受。

## 7. 求解思路：两阶段贪心

核心观察是：**这个问题的"难"只来自一个地方——好时段是稀缺的，大家会抢。**

所以算法分两步走：

**第一步：给时段排优先级。**

按"吸引力"从优到劣排序。吸引力由目标偏好决定：

- 经济优先：$-\!c_t$（电价越低越好）
- 绿色优先：$-\!e_t$（碳强度越低越好）

**第二步：依次填充时段，时段内按紧迫度分配。**

逐个取出吸引力最高的时段，把该时段的可用容量分配给在场的车辆。谁先拿？按**紧迫度**降序：

$$\text{urgency}_i(t)=\frac{\text{剩余需求}_i}{\text{剩余时段数}_i\times P_r\times\Delta t}$$

分母是"从此刻起一直满功率充，最多还能充多少"，所以紧迫度衡量的是**剩余时间里的需求占用量**：

- 紧迫度接近 1：必须立刻开始充，否则来不及 → 优先拿功率
- 紧迫度远小于 1：时间充裕 → 可以等，让位给更急的车

**为什么这个结构是对的：**

- 紧迫度机制保证了**刚性需求不被牺牲**。只停 1 小时的访客车紧迫度天然很高，永远第一时间拿到功率——不会出现"为了减碳把车主耽误了"。
- 时段排序机制保证了**弹性需求落到最优时段**。停留 9 小时的通勤车可以从容等待，直到绿电时段被排到前面才充电。
- 两个机制互相制约：越往后拖，紧迫度越高，最终会强制充电，从而保证可行性。

**算法复杂度**：$O(96\times M\log M)$，40 辆车时不到 1 毫秒，可以嵌入任何在线评测循环。

## 8. 与"只按电价调度"的区别

传统有序充电只看分时电价 $c_t$，把负荷推向电价低谷。但电价低谷通常在深夜，而光伏只在白天发电——**晚上充电用不到屋顶的绿电**。

本方案改成看碳强度 $e_t$，而 $e_t$ 与光伏出力强相关。于是充电负荷自动与光伏出力曲线重合，$G_t$ 显著下降。由于电费和碳排都只对 $G_t$ 计算，**两个目标同时变好，而不是互相折中**。

这正是实验部分观察到"策略 B 连电费都最低"的原因，也是这个题目在 "AI for Green" 主题下最有价值的洞察。
