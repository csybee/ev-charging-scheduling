## 问题定义

停车场内有一批交流充电桩，共享一台有容量上限的变压器，屋顶配有光伏。车辆陆续驶入、停留数小时后离开，离开时需要达到目标电量。

**决策变量**：每个时段、每辆车是否充电、以多大功率充电。

**目标**（可加权）：

$$\min\ \ \alpha \sum_t c_t \cdot G_t \Delta t \ +\ \beta \sum_t e_t \cdot G_t \Delta t \ +\ \gamma \max_t L_t$$

其中 $G_t$ 为时段 $t$ 的电网购电量，$c_t$ 为分时电价，$e_t$ 为电网碳强度，$L_t$ 为充电负荷。$\alpha,\beta,\gamma$ 对应"经济优先 / 绿色优先 / 平衡"三种偏好。

**约束**：

1. 每辆车在其停留区间 $[a_i, d_i)$ 内累计充入电量不少于需求量 $E_i$
2. 同时充电的车辆数不超过充电桩数量 $N$
3. 充电负荷不超过变压器容量 $P_{\max}$
4. 单桩功率不超过额定功率 $P_r$

详见 [docs/01-问题建模.md](docs/01-问题建模.md)。

## 方法：四个模块

按赛事细则对 A 赛道的描述（*改进数据处理、状态建模、预测与决策等模块*）组织代码：

| 模块 | 目录 | 内容 |
|---|---|---|
| **数据处理** | [`src/data/`](src/data/) | 充电场景生成、CSV 导入与列自动识别、异常剔除 |
| **状态建模** | [`src/model/`](src/model/) | 充电会话状态机：在场判定、剩余需求、紧迫度、能量流 |
| **预测** | [`src/predict/`](src/predict/) | 由历史充电记录预测当日逐时段充电需求，含误差评估 |
| **决策** | [`src/decision/`](src/decision/) | 三套调度策略：即插即充基线 / 分时电价优化 / 碳强度与光伏协同 |

调度算法思路：把 96 个时段按"吸引力"（电价或碳强度）从优到劣排序，依次填充容量；每个时段内部按车辆**紧迫度**（剩余需求 ÷ 剩余可充电量）排序分配功率。紧迫度高的车永远优先，因此不会出现车辆充不满；不紧迫的车则被推迟到绿电最充沛的时段。

## 结果：对比实验

固定随机种子 `20261031`，默认场景为办公楼停车场：40 辆待充电车辆、16 个交流桩（11 kW）、100 kW 变压器、100 kWp 屋顶光伏。运行 `python run_experiment.py` 可完整复现。

| 指标 | 即插即充基线 | 策略A · 电价优化 | 策略B · 碳光协同 |
|---|---|---|---|
| 变压器峰值负荷 (kW) | 176 | 100 | **100** |
| 总电费 (元) | 349.7 | 222.0 | **134.5** |
| 碳排放 (kgCO₂) | 235.1 | 182.4 | **96.0** |
| 光伏就地消纳率 (%) | 46.5 | 55.6 | **75.2** |
| 变压器过载时长 (h) | 3.00 | **0.00** | **0.00** |

**结论**：相比不做调度的基线，策略 B 同时把峰值负荷降了 43%、电费降了 62%、碳排放降了 59%，光伏就地消纳率从 46.5% 提升到 75.2%，并消除了变压器过载。

值得注意的是，**策略 B 连电费都是最低的**——因为它把充电安排在光伏出力最强的时段，用的是自己屋顶发的电，购电成本自然更低。这说明只盯分时电价的传统有序充电做法，会漏掉"绿电直供"这一层收益。

用 `python tools/sensitivity.py` 扫描车辆数 12–60 的完整区间后可以确认：**策略 B 在全部场景下的电费、碳排、光伏消纳率都是最优**；峰值优势则从车辆数 ≥ 20 开始成立（详见 [docs/03-实验报告.md](docs/03-实验报告.md) §3.5，其中也记录了车辆数很小时峰值优势反转的原因与改进方向）。

> 上表数值在固定随机种子下可复现。若你本地运行结果有细微出入（浮点舍入差异），以 `experiments/summary.csv` 为准。

## 快速开始

只需要 Python 3.7+，**无需安装任何第三方库**。

```bash
git clone https://github.com/csybee/ev-charging-scheduling.git
cd ev-charging-scheduling
python run_experiment.py
```

运行后会在 `experiments/` 下生成：

- `summary.csv` —— 三套策略的指标对比
- `schedule.csv` —— 每辆车的充电时段安排
- `load_curve.csv` —— 96 个时段的负荷、电价、碳强度与光伏出力
- `load_curve.svg` —— 负荷与能源曲线图

交互式演示（零依赖，双击打开）：

```
demo/index.html
```

演示页面支持拖动参数实时重算（车辆数 / 桩数 / 单桩功率 / 变压器容量 / 光伏装机 / 目标偏好），可导入赛题 CSV 数据，并可导出调度方案与指标结果。
